So funktioniert’s

  1. Wähle eine Farbe oder einen Minecraft-Partikel und male dein Muster. Mit „Spiegeln“ bleiben beide Flügel symmetrisch.
  2. Rechts siehst du live, wie die Flügel im Spiel aussehen — ziehe, um dich zu drehen.
  3. Gib deinen Flügeln einen Namen und veröffentliche sie in der Bibliothek.
  4. Du bekommst einen Befehl wie /twings install ab12cd34. Gib ihn einem Server-Admin — fertig!
